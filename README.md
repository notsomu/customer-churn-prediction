# Customer Churn Prediction System

## Overview
This project predicts telecom customer churn using Machine Learning classification models.

## Problem Statement
Customer churn is a major business challenge where customers stop using a company's services. This project analyzes customer data and predicts churn behavior.

## Tools & Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- Jupyter Notebook

## Features
- Data preprocessing
- Missing value handling
- Label encoding
- Exploratory Data Analysis
- Machine Learning model training
- Feature importance analysis
- Churn visualization

## Machine Learning Models
1. Random Forest Classifier
2. Logistic Regression

## Evaluation Metrics
- Accuracy Score
- Confusion Matrix

## Key Insights
- Customers with higher monthly charges were more likely to churn.
- Contract type strongly influenced retention.
- Random Forest achieved better prediction accuracy.
